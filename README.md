# Open Source Workflow Practice

This is a small Python project for practicing the GitHub contribution process in my Introduction to Open Source course at KBTU.

## What it does

The `hello.py` file contains a simple `greet(name)` function. When I run the file, it prints a greeting to the terminal.

## How to run it

1. Install Python 3.
2. Clone the repository.
3. Open the project folder and run `python hello.py`.

## Contributing

Changes to this repository can be discussed in GitHub Issues and submitted through pull requests from separate branches.
